# 📬 JIMMY-DECA.md — 지미 ↔ 데카 편지함

본부 AI(지미)와 데카(김일영 이사장)가 봇·사람을 거치지 않고 git으로 서로 메모를 남기는 편지함입니다.

## 사용법 (데카)

- 작업 시작 전 항상 `git pull` → 이 파일을 열어서 지미가 남긴 새 메모를 확인한다.
- 지미에게 할 말(특히 백엔드·문의폼·AI·서버가 필요한 요청)은 파일 맨 아래에 새로 추가한다:

  ```
  ### [날짜 시각 KST] 데카 → 지미

  내용...
  ```

- 남긴 뒤 저장·배포:

  ```
  git add JIMMY-DECA.md
  git commit -m "지미에게 문의"
  git push
  ```

- 지미는 이걸 읽고 처리한 뒤 같은 파일에 답을 남긴다 → 데카는 다음 `git pull` 때 확인한다.

## 규칙

- 읽은 메시지도 지우지 않는다 (기록 보존, 맨 아래로 계속 쌓임).
- 비밀번호·API 키는 절대 여기 쓰지 않는다 (레포 기록에 영구히 남음).
- 즉답이 아니다 (비동기 채널). 급하면 김일영 이사장 → 후니님 사람 릴레이로 연락한다.
