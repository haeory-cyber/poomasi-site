Purpose

목적과 목표

사회연대경제 진영의 활동가들에게 AI를 활용한 연대지능의 철학과 담론을 이해하고, 자기 현장에서의 문제해결 역량을 키우며, 교육훈련 과정을 통한 활동가 양성과 연대를 꾀합니다.
Curriculum

8회 커리큘럼

01

오리엔테이션 + AI와 시대읽기

담론 강의
  • 30분 — OT 자기소개 + AI 활용 현황 공유
  • 30분 — 담론 강의: 연대지능의 의미, 사회혁신운동의 기회와 가능성, 도메인특화 AI 만들기
  • 30분 — 이 과정에 거는 기대와 목표 나누기
  • 30분 — 과정 안내 + 7회 자동화 주제 사전 숙제
02

AI 하네스란 무엇인가

Claude Code + CLAUDE.md
  • 45분 강의 — 챗과의 결정적 차이, 바이브코딩, AI 에이전트 엔지니어링
  • 60분 실습 — Claude Code 설치 → 헬로월드 → CLAUDE.md 만들기
  • 15분 전체 공유 — 오늘 가장 놀란 지점, 1인 1마디

결과물자기 PC에서 Claude Code 작동 + 첫 CLAUDE.md

03

코딩·실행 및 안정망 인프라

VSCode + Git + GitHub
  • 30분 강의 — 코딩·실행·안정망이 왜 활동가에게 필요한가
  • 75분 실습 — VSCode + Git 초기화 + GitHub push
  • 15분 전체 공유 — 첫 commit 메시지

결과물자기 GitHub 레포 1개

04

AI와 함께 지식 백과사전 만들기

Obsidian + Quartz + CF Pages
  • 30분 강의 — 옵시디언이 왜 지식백과·도메인AI 먹이 자산인가
  • 75분 실습 — Obsidian vault → Quartz 변환 → Cloudflare Pages 배포
  • 15분 전체 공유 — 자기 위키 URL 채팅창 공개

결과물자기 위키 URL

05

인프라 2부 — 데이터 주권

Supabase
  • 30분 강의 — “데이터를 어디에 두는가”, 데이터 주권
  • 75분 실습 — Supabase 프로젝트 · 첫 테이블 · AI에게 쿼리 시키기
  • 15분 전체 공유 — 내 현장에 필요한 테이블 1개씩

결과물자기 DB 테이블 1개

06

웹사이트 만들기

운동의 얼굴
  • 15분 강의 — 왜 사회연대경제는 광고 없는 자기 사이트가 필요한가
  • 90분 실습 — AI와 한 페이지 사이트 + CF Pages 배포
  • 15분 — 전체 1분 시연

결과물자기 사이트 URL

07

자동화 프로그램 만들기

내 현장 문제 1개
  • 15분 강의 — 현장 문제를 코드로 푸는 방법론: 잘게 쪼개기
  • 90분 실습 — 사전 정한 주제로 자기 자동화 (막힌 사람 화면 공유 + 전체 풀이)
  • 15분 — 진행 공유 + 미완료자 숙제

결과물작동하는 자동화 1개

08

시연 + 회고 + 연대와 협동의 제안

매듭
  • 40분 시연 — 1인 5분, 자기 자산 자랑
  • 20분 회고 — 8회 전후 변화, 1인 2분
  • 45분 연대·협동 제안 세션 — 강사 제안 10분 / 각자 3분씩 25분 / 합의 10분
  • 15분 담론 회귀 — “도구를 만지면서 우리는 무엇이 되었는가”

결과물후속 모임 합의

Outcome

기대효과

01

담론적 환류

활동가가 AI를 단순 도구를 넘어 연대지능의 철학으로 이해. 사회혁신운동의 새 무기로 위치 잡기.

02

현장 도구화

수료생 각자가 GitHub 레포·위키·DB·웹사이트·자동화 5종을 자기 현장 자산으로 보유.

03

연대와 협동

1기 수료생이 후속 모임과 소속 단체 전파를 통해 사회연대경제 진영 내 AI 활동가 연대망 확장.

Operation

운영 방식

  • 모든 회차 녹화 → 2기 교재 + 결석자 보충
  • 회차 사이 텔레그램 단톡 운영 (설치·에러 24시간 내 답)
  • 1회 끝에 7회 자동화 주제 사전 숙제 부여
  • 수료 1개월 후 후속 모임 1회
